# Threat Research Pipeline

An automated platform that ingests untrusted samples, executes them in ephemeral detonation sandboxes, extracts forensic artifacts via Velociraptor, synthesizes threat intelligence using LLMs, and publishes Threat Analysis Reports to a public Report Hub.

## Language

**Sample**:
An untrusted executable binary or script submitted for automated dynamic analysis.
_Avoid_: File, upload, payload, binary

**Detonation Sandbox**:
An ephemeral, air-gapped container provisioned to safely execute a sample and capture its behavior.
_Avoid_: Docker machine, runner, box, VM

**Detonation Run**:
The time-bounded execution lifecycle of a single sample inside a detonation sandbox.
_Avoid_: Execution, scan, test, task

**Forensic Artifact**:
Forensic evidence extracted from a detonation sandbox post-detonation (e.g., modified files, persistence mechanisms, process trees, network sockets).
_Avoid_: Telemetry dump, log file, velociraptor report, raw data

**Threat Analysis Report**:
A structured intelligence report generated by an LLM that details sample behavior, MITRE ATT&CK techniques, and Indicators of Compromise (IoCs).
_Avoid_: Report, analysis, summary, AI output

**Report Hub**:
A public static website hosted via GitHub Pages that catalogs and displays published Threat Analysis Reports.
_Avoid_: Frontend, site, website, repo

**Detonation Host**:
The Linux compute instance in GCP that runs the Docker daemon, orchestration worker, and local sample queue.
_Avoid_: Server, machine, box, VM

**Submission Interface**:
The web form on the Report Hub that allows a user to select and transmit a sample directly from the browser to the Detonation Host.
_Avoid_: Uploader, form, upload page, frontend API

**Quarantine Store**:
A restricted directory on the Detonation Host that stores samples under their SHA256 hash with non-executable permissions (`chmod 0600`).
_Avoid_: Uploads folder, storage, file store, bucket

**Detonation Worker**:
An asynchronous background worker that sequentially dequeues samples, executes the Detonation Run, extracts Forensic Artifacts, and triggers AI synthesis.
_Avoid_: Runner, processor, task runner, job queue
